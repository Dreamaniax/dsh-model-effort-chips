# 鲲鹏像素素材位

四条**逐帧动画条**，每条 = 6 帧横排，档位切换时换条、帧率随档位提高。

| 文件 | 档位 | 动画 | 尺寸 |
| --- | --- | --- | --- |
| `off.png` | off | 沉睡呼吸 + 尾尖轻摆 | 3408 × 168 |
| `low.png` | low | 摆尾前游 + 水滴 | 3408 × 168 |
| `high.png` | high | 羽翼上下拍动、离水 | 3408 × 168 |
| `max.png` | max | 鲲鹏大翼拍动 | 3408 × 168 |

规格：

- **6 帧横排**，每帧 **568 × 168**，RGBA **透明背景**（只画生物本身）
- 帧率 = 3.5 + 6.5 × 档位，off 约 3.5fps、max 约 10fps
- 画在轨道**上方**的天空带（84 CSS px），滑条不会横穿画面
- 缺任意一条自动回退到程序化绘制（`kunpeng`），不会白屏

生成方式：GPT Image 出 3×2 精灵表（6 帧）→ 按网格切片 → 每帧裁到主体 →
统一 568×168 画布居中 → 横排合并。替换时保持 6 帧即可，代码不用改。
