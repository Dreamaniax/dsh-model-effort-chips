# 鲲鹏像素素材位

四张 **透明底** 像素风图，随档位切换。当前这组由 **GPT Image** 生成：2172×724 RGBA（真透明），裁切后铺到 568×168。

| 文件 | 档位 | 画面 |
| --- | --- | --- |
| `off.png` | off | 闭眼沉睡的小鲸鱼，Z 字气泡，细小水线 |
| `low.png` | low | 前游，身后溅起像素水花 |
| `high.png` | high | 背上长出羽翼，开始离水 |
| `max.png` | max | 完全鲲鹏：展翼、长尾、品红翼尖 |

规格：

- **568 × 168**，RGBA，**背景必须透明**（只有主体和它的小粒子）
- 画在轨道**上方**的天空带里（84 CSS px），所以滑条不会横穿画面
- 像素块边缘锐利；四张机位与配色连续
- 缺任意一张自动回退到程序化绘制（`kunpeng`），不会白屏

替换素材保持同名同尺寸即可，代码不用改。
