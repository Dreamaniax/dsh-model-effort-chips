# 鲲鹏插画素材位

四张 **像素风** 横版图，随档位切换。当前这组由 **GPT Image** 生成（2172×724 原图 → 裁切缩放到 568×184）。

| 文件 | 档位 | 画面 |
| --- | --- | --- |
| `off.png` | off | 小鲸鱼闭眼沉睡，Z 字气泡，水面 |
| `low.png` | low | 鲸鱼醒来前游，溅起水花 |
| `high.png` | high | 背上长出羽翼，开始离水 |
| `max.png` | max | 完全鲲鹏：展翼腾云，品红翼尖 |

规格：

- **568 × 184**，`device y=92` 是轨道线，主体必须画在它**上方**（否则被滑条横穿）
- 深色背景（≈ #0d0a22），主体居中，左右留白
- 像素块边缘锐利，不要抗锯齿；四张机位与配色连续
- 缺任意一张会自动回退到程序化绘制（`kunpeng`），不会白屏

替换素材时保持同名同尺寸即可，代码不用改。
