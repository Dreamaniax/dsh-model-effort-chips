# 鲲鹏插画素材位

把四张**同风格、同构图**的横版插画放这里，文件名固定：

| 文件 | 档位 | 画面 |
| --- | --- | --- |
| `off.png` | off | 小鲸鱼在水中游动，微弱水波 |
| `low.png` | low | 鲸鱼抬头，水花溅起 |
| `high.png` | high | 长出羽翼，离开水面 |
| `max.png` | max | 展翼腾云，最大翼展 |

要求：

- **横版**，推荐 **568 × 184**（面板 canvas 的 2 倍），比例约 3.09:1
- 深色背景（接近 #12141a），主体居中，四周留 8–12px 安全边距
- 四张的机位、光照、调色保持连续，只有角色形态与档位色变化
- PNG，不需要透明通道（面板背景本来就是深色）

放好后切到「鲲鹏动效 · 插画版」特效即可；缺图时会自动回退到程序化绘制，不会白屏。
