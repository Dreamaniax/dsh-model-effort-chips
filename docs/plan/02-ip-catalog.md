# 02 · 著名 IP 视觉母题目录：用程序化致敬表达 off → max

> 面向作者挑方案，不是营销文案。全目录只做**程序化致敬**：几何、配色、构图、节奏。
> **不使用**任何角色形象、logo、剧照、音效、外部贴图、Lottie/GIF/WebM。
> 所有条目都必须能落到「20 行 Canvas 2D 代码 + 一个状态数组」的粒度。

## 0. 一页纸结论

- 共 **9 个一级分类、48 条 IP/母题**；每条都给了 off→max 六阶段锚点、关键帧技术、难度、合规提示。
- 最稳的 3 类：**几何光效（漫威/DC）、神话纹样（山海经/敦煌/龙凤）、设计流派（Y2K/蒸汽波/构成主义）**——它们天生就是几何，合规风险最低。
- 最不建议直接画角色的：**黑神话悟空、哪吒 2、鬼灭之刃、蜘蛛侠**——角色/道具识别度太高，稍微画细就越线；只能取「金环+墨点」「红绫+金环」「水波+刀光」「半调网点」这种一层抽象。
- 合规风险最高的一条：**蝙蝠灯**。蝙蝠标志是强商标，哪怕只画「椭圆光斑」也可能被联想；本目录只允许「椭圆光斑 + 抽象双翼三角」，且 effect id 必须中性化。
- 推荐先做 5 条：**钢铁侠同心核心（S）、芙莉莲花田（S）、胆大党速度线（S）、黑客帝国代码雨（S）、星际穿越黑洞环（A）**——都在 88–164px 高画布可读，且不依赖角色。
- 全目录的 IP 配色只是灵感；**最终颜色必须从 `frame.accent` 派生**，否则会和宿主「绿→青→靛→紫→品红」的档位调色板打架。

## 1. 读表前必须对齐的 6 个事实

| 事实（来自 00-brief / lib/client.js） | 对本目录的约束 |
| --- | --- |
| `energy` 是 0..1 连续量，拖拽时是小数 | 六阶段是「设计锚点」，不是 6 个 UI 档位；实现必须按 `energy` 连续插值，不能按 index 写死 |
| 画布可视高度约 88–164px，宽 200–400px | 主体尺寸 ≥24px；线宽 ≥1.2px；同屏活动元素 ≤3 组；细节层级 ≤2 |
| 调色板固定绿→青→靛→紫→品红，`accent` 随档位变 | IP 专属色只做「色相偏移灵感」，实际填充用 `withAlpha(accent, a)` / `shade(accent, k)` 派生 |
| 只有 Canvas 2D，无 WebGL / 无第三方依赖 / 不联网 | 所有母题必须是 `arc` / `lineTo` / `bezierCurveTo` / `fillRect` / `clip` 能画出来的 |
| 档位数由模型声明（4 档 / 5 档） | 4 档模型没有 6 个停靠点，靠 `energy` 连续映射；同一个特效要能同时服务 4 档和 5 档 |
| `prefers-reduced-motion` 时只画一帧 | 高频闪烁、欧普条纹、故障抖动必须提供静态降级帧 |
| 每帧预算约 16ms，建议绘制 ≤3ms | 禁止每帧 `new` 上百对象、禁止每帧 `createLinearGradient`、`shadowBlur` 同时 ≤2 处 |

## 2. 六阶段锚点（全目录统一口径）

| 阶段 | 名称 | `energy` 区间 | 4 档模型大致落点 | 5 档模型大致落点 | 视觉职责 |
| --- | --- | --- | --- | --- | --- |
| 0 | off | `e = 0` | 第 1 档 | 第 1 档 | 静止/空场，只留一条基线或一个点 |
| 1 | minimal | `0 < e < 0.2` | 第 1 档 | 第 1 档 | 单一元素出现，证明「它醒了」 |
| 2 | low | `0.2 ≤ e < 0.4` | 第 2 档 | 第 2 档 | 结构成形：环、线、轮廓 |
| 3 | medium | `0.4 ≤ e < 0.6` | 第 2–3 档 | 第 3 档 | 结构增殖：多环、多轨、分叉 |
| 4 | high | `0.6 ≤ e < 0.85` | 第 3–4 档 | 第 4 档 | 质变前夜：离地、展开、临界 |
| 5 | max | `e ≥ 0.85` | 第 4 档 | 第 5 档 | 释放/完成态：爆发、飞天、反转 |

> 写法纪律：每个条目的阶段叙事必须写「第几阶段出现什么」，禁止写「逐渐变强」「越来越炫」。

**档位可读性三信号**（88–164px 下比颜色更可靠）：

1. **数量**：环数、粒子数、分叉数；
2. **尺寸**：主体半径、线宽、光柱长度；
3. **拓扑**：是否闭合、是否分叉、是否离场、是否反转。

只靠色相变化判档，在 88px 高、拖拽小数连续变化时会完全读不出来。

## 3. 难度口径（沿用 00-brief，别读反）

| 难度 | 含义 | 工期 | 本目录中的典型 |
| --- | --- | --- | --- |
| **S** | 纯数学，无状态机 | 约 1 小时出原型 | 同心环、代码雨、透视网格、莫尔条纹 |
| **A** | 需要状态机或粒子系统 | 约半天 | 呼吸法、法阵、花田、霓虹故障 |
| **B** | 需要物理/噪声/多图层 | 1–2 天 | 真实半调、流体触须、体积雾 |

> 注意：这里的 **S 是最简单**，不是最难；与常见 S/A/B/C 游戏评级相反。

## 4. 20 行法则与五个共用原语

**20 行法则**：每条 IP 的 `paint` 主体必须能用 ≤20 行表达——一个主几何 + 一个强度参数 + 一个时间相位。超过 20 行说明抽象层没做够，先删细节。

**五个共用原语**（48 条里 80% 都是它们的组合）：

| 原语 | 做法 | 常用 API | 典型条目 |
| --- | --- | --- | --- |
| 环 ring | 同心圆/椭圆，半径和透明度随 `e` 变 | `arc` + `stroke` | 钢铁侠、奇异博士、星际穿越 |
| 折线 polyline | 中点位移或正弦扰动生成折线 | `moveTo` / `lineTo` | 雷神、鬼灭、烛龙 |
| 粒子 particle | 固定数组复用，位置按速度积分 | `arc` / `fillRect` | 龙珠、高达、沙丘 |
| 轨迹 trail | 环形缓冲保存最近 N 帧位置，alpha 递减 | 数组 + `lineTo` | 闪电侠、星铁、黑神话 |
| 扫描线 scanline | 横向/纵向条带偏移或高亮 | `fillRect` + `clip` | 2049、Matrix、绝区零 |

**四条缓动**（够用，别引入库）：

```js
const easeOutCubic = (t) => 1 - Math.pow(1 - t, 3)
const easeInOutQuad = (t) => (t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2)
const smoothstep = (t) => t * t * (3 - 2 * t)
const easeOutExpo = (t) => (t >= 1 ? 1 : 1 - Math.pow(2, -10 * t))
```

**性能三纪律**：

1. `step` 里复用数组/对象，不每帧 `new`；
2. 渐变按 `energy` 分桶缓存（如 5 档），不每帧 `createLinearGradient`；
3. `shadowBlur` 同时最多 2 处，且只给主体，不给粒子。

### 5.8 艺术与设计流派（5 条）

**分类逻辑**：设计流派是「**规则即视觉**」——网格、斜线、条纹、液态金属，本身就是算法。它们几乎不需要 IP 知识，难度最低、合规最安全，适合作为第一批落地。注意欧普/故障类的高频闪烁必须做 `reduced-motion` 静态降级。

| IP / 母题 | 可程序化视觉母题（几何 / 配色 / 构图 / 节奏） | off → minimal → low → medium → high → max 六阶段叙事 | 关键帧技术（Canvas 2D 具体做法） | 难度 | 合规提示 |
| --- | --- | --- | --- | --- | --- |
| Y2K · 液态铬 | 液态铬球 + 四角星芒 + 半透明塑料；银/彩虹/粉；中心；旋转高光 | 0 无；1 一个球；2 球面高光；3 星芒；4 液态变形；5 铬色爆炸 + 光晕 | 圆 + 高光弧；四角星 `polygon`；HSL 色相偏移；变形用 `sin` 扰动半径；球半径 `lerp(8, 30, easeOutCubic(e))`，色相偏移 `lerp(0, 120, e)` | S | Y2K 为公共风格；不复制品牌 logo、专辑封面；彩虹铬是通用材质语言 |
| 蒸汽波 · 网格落日 | 透视网格 + 条纹落日 + 棕榈剪影；粉紫青；消失点构图；循环滚动 | 0 黑；1 网格线；2 落日圆；3 透视网格；4 棕榈剪影；5 全屏紫粉 + 故障 | 透视线到消失点；落日用横条纹 `clip`；棕榈扇形；故障切片；网格透视 `easeOutCubic(e)`，故障幅度 `lerp(0, 8, pow(e,2))` | S | 蒸汽波为公共风格；不复制具体专辑封面、石膏像照片；用自绘剪影 |
| 浮世绘 · 神奈川冲浪 | 扁平巨浪 + 泡沫爪 + 富士山三角；普鲁士蓝/米；对角线；缓慢卷起 | 0 无；1 一条浪线；2 浪头；3 泡沫点；4 巨浪卷；5 浪墙 + 飞沫 | 多层 `bezierCurveTo`；泡沫圆点；扁平色块；富士山三角；浪高 `easeOutCubic(e)`，泡沫数 `lerp(0, 24, e)` | A | 葛饰北斋原作已公有领域；**建议重绘构图**，不直接使用扫描图；不复制现代再创作版本 |
| 构成主义 · 红黑斜切 | 粗斜线 + 圆 + 矩形 + 红黑白；对角构图；硬切 | 0 白；1 一条斜线；2 圆 + 线；3 多块面；4 旋转构图；5 全屏对角线冲击 | 旋转矩形；圆；硬边无渐变；块面旋转 `lerp(0, 0.6, e)`，斜线数 `floor(lerp(1, 6, e))` | S | 构成主义为公共流派；不复制具体海报作品；红黑白是通用构成语言 |

### 5.9 网络文化 / 抽象梗（5 条）

**分类逻辑**：这一类的强度语言是「**信号被破坏**」——噪点、过饱和、像素化、冲击线。它最适合表达「高推理强度 = 信息过载」，但也是最容易踩肖像权/梗图版权的地方：只做滤镜语法，不贴真实照片。

| IP / 母题 | 可程序化视觉母题（几何 / 配色 / 构图 / 节奏） | off → minimal → low → medium → high → max 六阶段叙事 | 关键帧技术（Canvas 2D 具体做法） | 难度 | 合规提示 |
| --- | --- | --- | --- | --- | --- |
| 故障艺术 · Glitch | RGB 分离 + 扫描线 + 块状错位；青/品红/绿；全屏；随机跳变 | 0 正常；1 一条扫描线；2 轻微错位；3 RGB 分离；4 大面积撕裂；5 全屏崩溃 | 分区 `fillRect` 错位；三色叠加；噪点块；错位幅度 `lerp(0, 14, pow(e,2))`，RGB 偏移 `lerp(0, 6, e)` | S | 故障艺术为通用风格；不复制特定作品；不出现真实品牌 UI |
| 电子包浆 · Deep-fried | 过饱和 + 噪点 + 色阶断裂 + 压缩块；高对比；全屏；脉冲 | 0 干净；1 轻微饱和；2 噪点；3 色阶断裂；4 压缩块；5 全屏油炸爆光 | 半透明色块叠加；随机噪点 ≤40；用 overlay 矩形代替 `filter`；噪点 alpha `smoothstep(e)`，色块数 `floor(lerp(0, 10, e))` | S | 梗图常含真人肖像/不明版权；**只做抽象滤镜，不使用真实照片**；不出现真实人物 |

## 6. IP × 档位阶段设计法（4 套可复用模板）

> 先选模板，再填 IP。模板决定「阶段之间怎么变」，IP 只决定「长什么样」。

| 模板 | 0→5 骨架 | 适配 IP | 反模式（一定会翻车） | 实现要点 |
| --- | --- | --- | --- | --- |
| **形态进化型**<br>同一主体 A→B | 0 小/闭/单；1 长大 10%；2 结构出现（翼/环/枝）；3 结构过半；4 质变（离地/展开）；5 完成态（飞天/闭合/爆发） | 鲲鹏、钢铁侠、EVA、凤凰、黄金树、冰雪奇缘、黑神话金环 | 每档换一个主体；只放大不质变；max 才第一次出现结构（前 4 档零信息） | 一个 `morph` 标量 + 3 个阈值（0.2 / 0.5 / 0.85），全部用 `smoothstep`；结构件共用同一坐标系 |
| **能量蓄积型**<br>蓄能→临界→释放 | 0 静；1 微光；2 环/场；3 充能 60%；4 临界抖动；5 释放 | 龙珠、雷神、鬼灭、哪吒、原神、星铁、星际穿越、沙丘、明日方舟 | 全程线性变亮；没有临界点；max 只是「更亮」而没有释放；抖动与 `e` 无关 | `charge = pow(e,1.6)`；`e>0.8` 时叠加 `sin(time*30)` 抖动；max 触发一次性 `flash` 变量，画一帧后回落 |
| **环境异变型**<br>主体不变，世界被改写 | 0 常态；1 一处异常；2 异常扩散；3 环境改写 50%；4 主体被包围；5 完全异世界 | 光死夏、沙丘、Matrix、2077、黑神话、敦煌、蒸汽波、死亡搁浅 | 异常是随机噪声、与 `e` 无关；每档只加粒子数量；环境变了但和主体没有关系 | 背景层 + 前景层两层；背景层用 `e` 控制 `clip` 覆盖比例；前景保留一个固定锚点（一个点/一条线），让观众知道「世界变了，它还在」 |
| **角色登场型**<br>空场→前兆→到场 | 0 空场；1 前兆（风/尘/光）；2 轮廓；3 细节；4 压迫感（阴影/低角）；5 到场（仍是抽象体） | 咒术领域、胆大党、高达、蝙蝠灯、Coco 光门、EVA 十字、2049 巨像、绝区零 | max 直接贴可识别剪影（合规红线）；前 3 档全空；登场没有空间关系（从画布外进来 vs 原地出现） | `entrance = smoothstep((e-0.4)/0.45)`；位置从画布外 `lerp` 到锚点；用 `clip` 控制显现；max 也只画几何体，不画五官 |

**模板选择决策表**：

| 你的问题 | 选模板 |
| --- | --- |
| 主体本身会不会变形/长结构？ | 形态进化型 |
| 有没有一个明确的「释放/爆发」瞬间？ | 能量蓄积型 |
| 真正的主角是不是环境/世界？ | 环境异变型 |
| 高潮是不是「某个东西出现了」？ | 角色登场型 |

**全局反模式清单**（四套模板共用）：

1. **六阶段写成「逐渐变强」**——不可实现，也无法验收。
2. **每档换一套配色**——破坏「同一条命」的连续感；颜色应只随 `accent` 变。
3. **max 才出现全部元素**——前 4 档没有信息量，拖拽时像卡住。
4. **只靠粒子数量表达强度**——88px 高画布上 50 颗和 80 颗看不出差别。
5. **靠 `shadowBlur` 堆亮度**——60fps 下直接掉帧，且浅色主题会糊成一片。
6. **可识别剪影/logo/专有纹样**——合规红线，直接出局。
7. **档位之间没有阈值**——线性插值但视觉上没有「跨过去」的瞬间，用户读不出档。
8. **忽略 4 档模型**——按 6 档写死 index，4 档模型上会跳变。

## 9. 与现有 `kunpengEffect` 的范式对照

`kunpengEffect` 已经是「形态进化型」的标准答案。新 IP 不用从零想，先看能复用它哪一块：

| 现有函数 / 做法 | 它解决了什么 | 可复用到哪些 IP |
| --- | --- | --- |
| `kunpengScaleFor(e) = 0.5 + 0.85e` | 主体尺寸随档位线性长大 | 钢铁侠核心、凤凰、黄金树、哪吒金环 |
| `kunpengWingFor(e) = smoothstep((e-0.4)/0.45)` | 在 40%–85% 区间「长出结构」 | 所有形态进化型的阈值骨架；EVA 力场、高达线框 |
| `kunpengLiftFor(e) = 3 + 56 * pow(e,2.2)` | 非线性「离场」，max 才明显 | 鲲鹏、凤凰、星际穿越、Coco 光门 |
| `kunpengAngleFor(e)` | 姿态随档位变化（-0.08 → -0.63 rad） | 雷神闪电、胆大党透视、高达推进器 |
| `kunpengRibbonY` 双层正弦 | 波带既有形变又有流动 | 鬼灭呼吸法、浮世绘巨浪、蒸汽波网格 |
| `drawKunpeng` 的 `quadraticCurveTo` 身体 | 极简有机形体，20 行内可画 | 所有「抽象容器」类角色替身（不画五官） |
| `shadowBlur` 只给主体 | 发光但不糊 | 所有能量蓄积型 |

**复用纪律**：复用「函数形状」，不复用「鲸鱼造型」。鲸鱼是鲲鹏的公共母题，但不要把鲸鱼身体直接搬到凤凰/龙/哪吒上——那会变成四不像，也会让观众读不出 IP。
